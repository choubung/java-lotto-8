# java-lotto-precourse

## 🚀 기능 구현 목록

### 1. 입출력 (View)
- [X] **입력**
    - [X] 로또 구입 금액 입력
    - [X] 당첨 번호 입력
    - [X] 보너스 번호 입력
- [ ] **출력**
    - [ ] 발행한 로또 수량 및 번호 (로또 번호는 오름차순)
    - [ ] 당첨 내역 출력
    - [ ] 소수점 둘쨰 자리에서 반올림한 수익률
    - [X] 에러 메시지 출력 (`[ERROR]` 접두사 포함)

### 2. 비즈니스 로직 (Domain)
- [X] **핵심 객체 Lotto**
    - [X] field: 당첨번호(중복 x, 1~45)
    - [X] 당첨 번호 유효성 체크 메소드
- [X] **부가 객체 LottoInfo**
    - [X] field: 1~5등, 꽝의 정보(번호 개수, 금액)
    - [X] 입력 정보에 따라 등수 반환하는 메소드
- [X] **관리 객체 LottoMachine**
    - [X] 구매 로또 저장
    - [X] 전체 흐름 관장
- [X] **관리 객체 LottoCalculator**
    - [X] 당첨 번호, 보너스번호 저장
    - [X] 당첨 여부 저장
    - [X] 수익률 계산
    - [X] 당첨 통계 저장

### 3. 예외 처리 (Exception)
> 모든 예외는 `IllegalArgumentException`을 발생시키며, `[ERROR]`로 시작하는 메시지를 출력한다.

- [X] **입력 유효성 검증**
    - [X] [예외] 숫자가 아닌 문자가 포함된 경우 (숫자 입력 시) (parser)
    - [X] [예외] 정해진 구분자(쉼표 등) 형식이 아닌 경우 (parser)
- [X] **비즈니스 규칙 검증**
    - [X] [예외] 숫자 범위(1~45)를 벗어난 경우 (lotto)
    - [X] [예외] 로또 구입 금액은 1,000의 배수여야 함 (validator)
    - [X] [예외] 중복된 값이 있는 경우 (lotto)
