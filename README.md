# java-lotto-precourse
## 프로그램 설명
### 간단한 로또 발매기
로또 금액만큼 로또를 발매하고, 입력 받은 당첨 번호를 토대로 당첨 내역 및 수익률을 출력한다.

**로또 정보**
- 로또: 중복되지 않는 숫자 6개 (자동 발매)
- 당첨번호: 중복되지 않는 숫자 6개와 보너스 번호 1개 (사용자가 입력)
- 로또 번호의 숫자 범위는 1~45
- 로또 1장은 1,000원

**당첨 기준과 금액**
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원
<br>

## 입출력
### 입력
- 로또 구입 금액 (1,000원 단위로 입력)과 당첨 번호 (쉼표 기준으로 구분), 보너스 번호를 입력받는다.

### 출력
- 발행한 로또 수량 및 정보(오름차순), 당첨 내역, 수익률을 출력한다.

### 입출력 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
<br>

## 프로그램 기능
- 로또 발매 및 발행 내역 출력
- 당첨 내역 출력
- 수익률 출력
- 예외 처리
  - 로또 금액 입력
    - 로또 구입 금액이 정수가 아닌 경우 (문자 등)
    - 1,000의 배수인 양의 정수가 아닌 경우
  - 당첨 번호 입력
  - 보너스 번호 입력

## 프로그래밍 요구사항
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현
- 3항 연산자를 쓰지 않는다
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현 
- else 예약어를 쓰지 않는다 (switch/case도 비허용)
- 단위 테스트 작성
